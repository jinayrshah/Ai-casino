# AI Casino: The Ultimate Turing Test 🎰🤖

An interactive, futuristic casino-style game that tests your ability to distinguish between Artificial Intelligence and human reality. Built with a robust 6-tier AI fallback system and real-time multiplayer websockets.

## 🎮 Game Modes

### Round 1: AI Image Challenge
- Read an original image prompt and write your own creative interpretation.
- The game leverages a sophisticated **6-Tier Image Generation Fallback System** to guarantee an image is generated, gracefully cascading from Puter.js, to client-side Pollinations, to backend Pollinations, to Hugging Face, down to SVG fallbacks.
- Compare your generated image with the AI's version.

### Round 2: Reality Check
- Watch a rapid-fire sequence of videos.
- You have 60 seconds to identify which videos are real life and which were entirely generated by AI.
- Score points based on your speed and accuracy.

### Round 3: The Turing Test (Real-time Chat)
- Engage in a live, blind chat session.
- You will be connected either to a **Live Human Host** (via WebSockets) or the **Gemini 1.5 Flash AI model**.
- You have 3 messages to determine if you are talking to a human or a machine.

## 🚀 Technical Architecture

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Lucide React
- **Backend:** Node.js, Express, Socket.io (Real-time WebSocket communication)
- **AI Models & Services:** Google Gemini 1.5 Flash (for Chat), Puter.js, Pollinations.ai, Hugging Face (for Image Generation)
- **Deployment:** Vercel (Frontend), Render (Backend)

### 🧠 Robust AI Integration
This project features an extremely resilient AI integration system designed to bypass network constraints, API rate limits, and service downtimes:
- **Chat:** Automatically falls back from Google Gemini API directly to a backup AI provider if rate limits are hit.
- **Images:** Utilizes a highly complex 6-layer fallback architecture prioritizing free, unauthenticated APIs and elegantly dropping down to backup services instantly if one fails.

## 🛠️ Local Development

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/jinayrshah/Ai-casino.git
   cd Ai-casino
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Environment Variables**
   Create a `.env` file in the root directory and add your keys:
   ```env
   VITE_GEMINI_API_KEY=your_gemini_key_here
   VITE_WS_URL=ws://localhost:8080
   ```

4. **Start the Development Servers**

   **Start the Backend WebSocket Server:**
   ```bash
   npm run host
   ```
   
   **Start the Frontend Game Client:**
   ```bash
   npm run dev
   ```
